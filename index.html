App Store Keyword Density Checker

Enter an App Store URL, app id or search term to see which words and phrases a listing's description leans on. Data comes straight from Apple's public iTunes Lookup API in your browser.

How it works. The description is lower-cased and split into words. Phrases that start or end with a common stopword are skipped. Density is the share of description words taken up by a term. name marks terms whose words all appear in the app name. App Store search is generally understood to rely on the app name, subtitle and keyword field rather than the description, so treat this as a readability and messaging check, not a ranking score.
